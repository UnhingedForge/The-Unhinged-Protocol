# The Unhinged Protocol

The Unhinged Protocol is proprietary Windows desktop organization software
built free for everyone.

## Project status

This project is in its initial development stage. Source code, build
instructions, supported Windows versions, and release details will be added as
development progresses.

## Repository scope

This repository represents the contents of the local `Source_Files` directory.
General project documentation, generated images, and release artifacts are
maintained outside this repository unless they are intentionally added later.
